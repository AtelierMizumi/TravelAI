# BUG-008: Base ref không tồn tại làm gate PASS lặng lẽ

- **Mức độ**: High (gate bị vô hiệu hóa mà không báo)
- **TC liên quan**: TC-20 (FR-009) — chưa viết
- **Tái hiện**: `bash scripts/governance-check.sh no-such-ref` trên repo bất kỳ.
- **Mong đợi**: FAIL với thông điệp nêu base ref không hợp lệ; exit khác 0.
- **Thực tế**: TAGF-4 và test-first đều PASS; output `Governance: ALL CHECKPOINTS PASS`; exit 0. Lỗi `git log` bị nuốt bởi `2>/dev/null`.
- **Root cause**: `git log ... 2>/dev/null` và `git diff ... 2>/dev/null` trả chuỗi rỗng khi ref sai, và rỗng được coi là "không có vi phạm".
- **Sửa dự kiến**: kiểm `git rev-parse --verify "$BASE^{commit}"` trước; nếu không hợp lệ thì FAIL với thông điệp rõ.
- **Test hồi quy**: TC-20 (viết trước, thấy đỏ, rồi sửa).
- **Trạng thái**: Open. Chưa sửa trong phiên này, theo phạm vi duyệt spec.
