# BUG-007: Heuristic test-first nhận nhầm file có chữ "test" hoặc "spec" trong tên

- **Mức độ**: High
- **TC liên quan**: TC-17, TC-18 (FR-005)
- **Tái hiện**: thêm `backend/src/main/java/x/InspectionService.java` không kèm test rồi chạy gate với base ref.
- **Mong đợi**: `FAIL test-first` (thiếu test thật).
- **Thực tế**: `PASS test-first` vì `grep -v '(test|spec)'` loại nhầm "Inspection" (chứa "spec"), và `grep -i '(test|spec)'` coi `docs/contest-notes.md` là test change.
- **Root cause**: khớp chuỗi con bất kỳ thay vì nhận diện file test theo mẫu tên hoặc thư mục.
- **Sửa**: định nghĩa `TEST_RE` theo mẫu tên và thư mục; `SRC` loại file khớp `TEST_RE`, `TEST` chỉ lấy file khớp `TEST_RE`.
- **Test hồi quy**: TC-17, TC-18 (đỏ trước khi sửa), TC-19 (đặc tả, pin hành vi test thật).
- **Trạng thái**: Fixed trên `spike/spec-kit` (chưa commit).
