# BUG-006: Gate in nguyên nội dung dòng chứa secret vào log CI

- **Mức độ**: Critical
- **TC liên quan**: TC-16 (FR-002, Constitution nguyên tắc 1)
- **Tái hiện**: `mkdir t && cd t && git init -q && git config user.email a@b && git config user.name a && mkdir scripts && cp ../scripts/governance-check.sh scripts/ && echo 'KEY = "AKIAIOSFODNN7EXAMPLE"' > app.txt && git add -A && bash scripts/governance-check.sh`
- **Mong đợi**: `FAIL TAGF-1/2 ... app.txt:1`, không có chuỗi khóa trong output.
- **Thực tế**: output có `app.txt:1:KEY = "AKIAIOSFODNN7EXAMPLE"`, tức khóa bị in ra log CI.
- **Root cause**: `git grep -n` in cả dòng khớp, script gán thẳng output vào biến rồi echo.
- **Sửa**: pipe qua `cut -d: -f1,2` để chỉ giữ `file:dòng`.
- **Test hồi quy**: TC-16 (đỏ trước khi sửa, xanh sau khi sửa).
- **Trạng thái**: Fixed trên `spike/spec-kit` (chưa commit).
