# BUG-001: Job Governance trong CI bị bỏ qua vì thiếu script

- **Mức độ**: High
- **TC liên quan**: (CI job `governance`)
- **Tái hiện**: `grep -n governance-check .github/workflows/ci.yml` rồi `ls scripts/governance-check.sh` trên `main`.
- **Mong đợi**: script tồn tại và chạy được trên PR.
- **Thực tế**: CI in `scripts/governance-check.sh not on this branch yet: skipped`, job vẫn xanh.
- **Root cause**: script chỉ được commit trên `feat/wbs-1.8.2-docker-compose-integration` (commit 7344416), chưa đưa về `main`. CI fallback ẩn lỗi bằng cách bỏ qua.
- **Test hồi quy**: TC-01 trong `test-governance-check.sh` (harness fail nếu script thiếu).
- **Trạng thái**: Partially fixed. Script đã có trên `spike/spec-kit` (chưa commit). Fallback "skipped" trong `.github/workflows/ci.yml` vẫn còn, sẽ bỏ ở task D1 sau khi merge vào `main`.
